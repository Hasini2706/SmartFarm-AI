## ✔ API Endpoints

| Method | Endpoint | Auth Required | Description |
| :--- | :--- | :--- | :--- |
| **POST** | `/api/auth/register` | No (Rate Limited) | Registers new users (prevents duplicate emails/usernames, validates password strength). |
| **POST** | `/api/auth/login` | No (Rate Limited) | Authenticates credentials and returns JWT access + refresh token pair. |
| **POST** | `/api/auth/logout` | No | Invalidates and revokes active refresh tokens. |
| **POST** | `/api/auth/refresh` | No | Rotates expired access tokens using the replay-protected refresh token. |
| **GET** | `/api/auth/me` | Yes (Bearer) | Retrieves the profile details of the currently authenticated user. |
| **POST** | `/api/auth/google` | No | Exchanges a Google client credential token for JWT session tokens. |
| **GET** | `/api/auth/google/login` | No | Redirects browser to Google's consent screen. |
| **GET** | `/api/auth/google/callback` | No | Handles authorization code token swaps and logs user in. |

## ✔ Database Changes
* **Table:** `users`
* **Modifications:**
  * `hashed_password`: Made `NULLABLE` (allows Google-registered accounts without local credentials).
  * `name`: Added `VARCHAR(255)` column (syncs with `full_name`).
  * `password_hash`: Added `VARCHAR(255)` column (syncs with `hashed_password`).
  * `google_id`: Added `VARCHAR(255)` unique indexed column.
  * `updated_at`: Added `TIMESTAMP` column.

## ✔ Security Improvements
1. **Password Security:** Multi-round `bcrypt` hashing (12 salt rounds) prevents plaintext storage.
2. **API Rate Limiting:** limits `/login` and `/register` requests to 5 per 15 minutes per IP.
3. **Replay Protection:** One-time use rotated refresh tokens mitigate token hijacking risks.
4. **Header Hardening:** Added CSP, frame-options clickjacking mitigation, and strict transport headers.
5. **CORS Guarding:** Enforced backend origin limits restricting unauthorized cross-domain scripting.
